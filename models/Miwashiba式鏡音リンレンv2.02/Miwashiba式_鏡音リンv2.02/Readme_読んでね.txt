■モデルについて

『Miwashiba式鏡音リンv2』

VRoid　Studioでベースを制作、
PmxEditorでモーフなどの細部調整をしたMikuMikuDance専用モデルです。
おまけで色違い、またツヤ部分のスフィア違い（SPA付がツヤ強め）差分も入っています。

一部パーツは透過素材でできているので、読み込み時に境目が気になる場合がありますが、
「ミニマップをオフ」で大分軽減されます。（＋アンチエイリアスオフも効果的）
シェーダーによっても透過の境目が目立ち、気になることがあります。


モデル名クレジットは任意ですが、記載の際は「Miwashiba式鏡音リン」でお願いします。
作者名なら「△○□×」でも「みわしいば」「Miwashiba」でも表記ゆれはお好きなように。
